Ảnh nguồn

Nếu không chọn ảnh nào, ảnh thử (3 chấm màu) sẽ được dùng.

Dung lượng file SVG

Tính theo đúng nội dung file SVG sẽ lưu (UTF-8, 1 KB = 1024 B). Hình nào làm file vượt mục tiêu sẽ không được thêm vào. Khi bật mục này, “số hình tối đa” bên dưới chỉ còn là mức trần.
